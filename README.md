# Lavi Games

Studio hub for [lavigames.com](https://lavigames.com) — links to published games.

## Games

- [Poll Warrior](https://pw.lavigames.com)
- [Territory Conquest](https://tc.lavigames.com)

## Develop

```bash
npm install
npm run dev
```

## Deploy

Deploy as a separate Vercel project and point `lavigames.com` at it.
